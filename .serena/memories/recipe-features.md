Recipe UX: Home shows published recipes in grid + hero section with search bar (navigates to /search); updates on recipeUpdated/favoriteToggled; loads recipes in batches of 30 and only shows "Load More Recipes" when filtered results exceed 30. RecipeCard component: shows image, timer badge, like/save buttons, categories, title, description preview (2 lines), avg star rating, like count label, author name/avatar, and difficulty badge; supports actionOverlay prop for profile page overlays. Search page: URL params sync (q/category/difficulty/sort); title-only keyword filter; multi-select category checkboxes; difficulty filter; sort options: Most Popular (likes), Newest First, Difficulty Low→High; debounced search history (1.5s, max 10 per user, deduped); recent history chips with clear button; reset filters button. RecipeDetail: view recipe with image, categories, date, author (links to profile), avg star rating, total time, difficulty; like/favorite toggles; view count tracked (user or guest via viewerType); ingredient checklist with check/uncheck; numbered instructions; reviews section: 1 review per user (upsert), star rating 1-5, delete own reviews; owner sees edit/delete buttons; pending/suspended users see info banner and interactions disabled. CreateRecipe: create/edit mode (via :id param); comprehensive validation (title 3-100 chars, description 10-500 chars, categories 1-3, prepTime 1-1440, cookTime 0-1440, servings 1-100, valid image URL, ≥1 ingredient with name+quantity, ≥1 instruction ≥5 chars); multi-select category dropdown (max 3); image URL (optional, has default); new recipes status=pending; editing preserves status unless rejected→pending; blocked screen for pending/suspended users. Random Recipe Suggestion: Home page has "Surprise Me" button that opens modal with random recipe suggestion; suggested recipes meet quality constraints (>= 5 likes AND >= 1 review) if such recipes exist, otherwise falls back to any published recipe; suggestion modal shows recipe image, title, difficulty badge, like count, review count, and "View Recipe" / "Try Another" buttons; accessed via storage.getRandomSuggestion() function; Guest compatibility: guest users can view suggestions and navigate to recipes but do NOT increment view counts or analytics; Playwright tests (3 spec files) cover modal flow, navigation, guest mode integration, accessibility, and responsiveness (35 ACs, 47 tasks, 6 phases). Profile: view own or other user's profile; profile header with avatar, username, cookingLevel badge, bio, location, joined date; edit profile modal (avatar selector from 6 presets or custom URL, firstName, lastName, username, email, bio, location, cookingLevel); tabs: recipes (own shows all statuses with status badge + edit/delete overlays; others see published only) and favorites; edit/delete own recipes from profile with confirmation modals.
