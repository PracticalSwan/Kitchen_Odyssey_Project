AuthContext: initializes storage (seeds if empty), loads current user from localStorage, tracks loading state. login(email,pw) -> storage.login; sets user status to 'active' (from 'inactive'), updates lastActive, returns {success, error}. logout -> storage.logout(userId) sets user status to 'inactive' (from 'active'), clears current user state. signup creates user with role:'user', status:'pending', generates id/joinedDate/favorites/viewedRecipes defaults, saves user, logs activity ("joined platform"), calls recordNewUser for stats, then auto-logs in via storage.login. updateProfile merges updates into user and persists to both storage and currentUser. enterGuestMode() -> generates/recovers guest ID from localStorage (__GUEST__ format), sets isGuest=true, registers storage event listener for tab sync, handles localStorage errors gracefully; exports isGuest, enterGuestMode along with other context values.

User Status Flow: All seed users start as 'inactive'. Login changes status from 'inactive' to 'active'. Logout changes status from 'active' to 'inactive'. Pending/suspended users retain their status (account state, not session state).

Derived flags: isAdmin (role=admin), isPending (status=pending), isSuspended (status=suspended), isGuest (guest mode flag), canInteract (user exists AND status=active AND NOT admin AND NOT isGuest). Activity tracking: updateLastActive heartbeat every 1 min, recordActiveUser hourly, updates lastActive on beforeunload/pagehide (but NOT on logout - logging out isn't an "active" activity). Listens for favoriteToggled to sync current user state.
